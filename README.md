# Stimulus Bank

从细纲写正文时，我挑中、并最终写进正文的刺激表达，都收在这里。攒下来的，就是我的品味。

## 用处

1. **给 AI 当例子**：让它出的候选更像我会挑的。
2. **回头看偏好**：看自己总往哪几种来源去找。

## 目录

- `标签.md`：现有的来源标签。上面一张总表按条数从多到少排；下面每个标签一节，列出它的所有记录，点链接直接跳到那一条记录。
- `记录/`：每篇一个文件，文件名是"日期-篇名.md"，例如 `2026-11-14-猫猫分胡萝卜.md`。

## 一条记录记五样

每条记录以一个小标题开头，标题就是锚点，例如 `### 拼车`。标签页里，每条记录的链接名也是锚点，点了靠这个小标题跳到这一条。

- **锚点**：我标的字词或意思，后面附上细纲里的那一句
- **写成**：最后写进正文的句子
- **来源**：标签，可以有多个；每个标签都链接到 `标签.md` 里它那一节
- **效果**：读者的反应，比如好笑、可爱、心疼
- **为什么**：一句话，用我自己的话，可以空着

例子：

```
### 拼车

- **锚点**：拼车（细纲：雨天打不到车，费了很大劲才拼上一辆已经载着客人的出租车）
- **写成**：钱包余额，让我果断地选择了拼车。
- **来源**：[穷富标志](../标签.md#穷富标志)
- **效果**：好笑（自嘲）
- **为什么**：
```

## 入库规则

- 只记最后写进正文的句子；没选的候选不记。
- 来源标签先由 AI 标，我再改。现有标签能用就用，用不上就新加一个。
- 每次入库后，同时更新 `标签.md`：总表里的条数和顺序，以及每个标签那一节下的记录（写成的句子 + 以锚点为名、跳到那一条的链接）。
- 链接末尾的跳转名按 GitHub 的规则写：去掉标点，空格换成 `-`。同一篇里锚点重名的，第二条起末尾依次加 `-1`、`-2`。
