# Stimulus Bank

每一篇已确定池里的刺激点，连同它们在正文里最后写成的样子，都收在这里。攒下来的，就是我的品味。

## 用处

1. **给 AI 当例子**：让它出的候选更像我会挑的。
2. **回头看偏好**：看自己总往哪几种分类去找。

## 目录

- `标签.md`：现有的分类标签。上面一张总表按条数从多到少排；下面每个标签一节，列出它的所有记录，点链接直接跳到那一条记录。
- `记录/`：每篇一个文件，文件名是"日期-篇名.md"，例如 `2026-11-15-秘密是装在肚子里的.md`。

## 一条记录记四样

每条记录以一个小标题开头，标题是刺激点的短名，例如 `### 捂嘴点头`。标签页里，每条记录的链接名也是这个短名，点了靠这个小标题跳到这一条。

- **刺激点**：一句话说清这个刺激点是什么
- **实写正文**：它在正文里最后写成的样子
- **分类标签**：可以有多个；每个标签都链接到 `标签.md` 里它那一节
- **为什么**：一句话，用我自己的话，可以空着

例子：

```
### 捂嘴点头

- **刺激点**：松鼠转身就忘了自己说没说过；猫猫连“是”都不肯出声
- **实写正文**：小松鼠准备走，刚走出去十几步，有些不放心，又折回来，压低声音问：“我刚才……是不是告诉过你一个秘密？”猫猫刚想说是，突然自己捂住嘴，只是用力点头。
- **分类标签**：[角色人设](../标签.md#角色人设)
- **为什么**：
```

## 入库规则

- 只收已确定池里的刺激点，每条配它在正文里最后写成的样子；池子以外的句子、没选的候选都不记。
- 分类标签先由 AI 标，我再改。现有标签能用就用，用不上就新加一个。
- 每次入库后，同时更新 `标签.md`：总表里的条数和顺序，以及每个标签那一节下的记录，每条写成 `[刺激点短名](记录/篇名文件.md#刺激点短名)：实写正文`。
- 链接末尾的跳转名按 GitHub 的规则写：去掉标点，空格换成 `-`。同一篇里短名重名的，第二条起末尾依次加 `-1`、`-2`。
