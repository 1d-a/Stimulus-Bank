# Stimulus Bank

每一篇已确定池里的刺激点，连同它们在正文里最后的样子，都收在这里。攒下来的，就是我的品味。

## 用处

1. **给 AI 当例子**：让它出的候选池更像我会挑的。
2. **回头看偏好**：看自己总往哪几种分类去找。

## AI 怎么用这个库

- 开工时通读整个库，学我的倾向，但不限定死。
- 库里已有的分类和新方向各占多少，开工时由我定。

## 目录

- `标签.md`：现有的分类标签。上面一张总表按条数从多到少排；下面每个标签一节，列出它的所有记录，点链接直接跳到那一条记录。
- `记录/`：每篇一个文件，文件名是"日期-篇名.md"，例如 `2026-11-15-秘密是装在肚子里的.md`。文件开头是篇名和日期，下面每个刺激点一条记录。

## 一条记录记四样

每条记录以一个小标题开头，标题是刺激点的短名，例如 `### 捂嘴点头`。标签页里，每条记录的链接名也是这个短名，点了靠这个小标题跳到这一条。

- **刺激点**：一句话说清这个刺激点是什么
- **实写正文**：它在正文里最后的样子
- **分类标签**：可以有多个；每个标签都链接到 `标签.md` 里它那一节
- **为什么**：一句话，用我自己的话，可以空着

例子：

```
### 捂嘴点头

- **刺激点**：松鼠转身就忘了自己说没说过；猫猫连“是”都不肯出声
- **实写正文**：小松鼠准备走，刚走出去十几步，有些不放心，又折回来，压低声音问：“我刚才……是不是告诉过你一个秘密？”猫猫刚想说是，突然自己捂住嘴，只是用力点头。
- **分类标签**：[角色人设](../标签.md#角色人设)
- **为什么**：
```

## 入库

### 收什么

- 只收已确定池里的刺激点，每条配它在正文里最后的样子。
- 池子以外的句子、没选的候选，都不收。

### 怎么走

1. 整篇写完、审完、改完、定好篇名后，AI 建一份入库文档：最上面列出现有的全部分类标签，只供参考，不上传；下面是要上传的记录，上传后就是这个样子。
2. 分类标签由 AI 先标，我再改。现有标签能用就用，用不上就新加一个。
3. 我在入库文档里改完，AI 再推到这里：新增这一篇的记录文件，同时更新 `标签.md`。

### 标签.md 怎么更新

- 总表里的条数和顺序跟着变。
- 每个标签那一节下列出它的所有记录，每条的格式是 `[刺激点短名](记录/篇名文件.md#刺激点短名)：实写正文`。
- 链接末尾的跳转名按 GitHub 的规则写：去掉标点，空格换成 `-`。同一篇里短名重名的，第二条起末尾依次加 `-1`、`-2`。
